# Step 11 Demo Script

## Goal
Show one ICP-fit prospect the exact core workflow in 15 minutes without wandering into generic feature-tour behavior.

## Demo Outcome
By the end of the demo, the prospect should understand:
- how to configure providers
- how personas affect repeatable output style
- how one brief can be run and compared across providers
- how saved conversation history and analytics support repeatable client delivery

## Demo Rules
- do not freestyle the path
- do not lead with infrastructure or admin surfaces
- do not start with AI Roundtable, Goal Hub, or Pipeline unless the prospect asks
- do not over-explain internal implementation details
- do not show unfinished or low-signal areas first

## Exact Demo Path
1. Home page
- explain the product in one sentence
- point to the activation checklist and core workflow surfaces

2. Settings
- open `/settings`
- show API provider configuration
- explain that the product depends on at least one configured provider
- do not spend time in unrelated settings unless asked

3. Personas
- open `/personas`
- show one existing persona or create one simple client-style persona
- explain that personas are how repeatable client voice/instructions are reused

4. Multi-Chat
- open `/multi-chat`
- enter one short but realistic client brief
- run it with at least two active models/providers if available
- explain that the conversation is saved, not lost in ad hoc tab switching

5. Comparison
- open `/comparison`
- show the saved work side by side
- explain how the user can review differences and decide what to reuse
- this is the core value moment and should get the most attention

6. Analytics
- open `/analytics`
- show that saved comparison-ready work becomes measurable
- explain that the goal is not vanity chat volume, but repeatable saved client work

## Optional Surfaces
Only show these if directly relevant:
- `/ai-roundtable`
  - use when the prospect values multi-agent debate around one goal
- `/goal-hub`
  - use when the prospect manages deliverables through explicit goal tracking
- `/pipeline`
  - use when the prospect asks about staged review/handoff workflows

## Recommended Demo Narration
Use this exact framing:
- "This is not trying to beat ChatGPT as a generic chatbot."
- "It is for teams or solo operators who need the same brief run across providers, with reusable instructions and saved history."
- "The value is not one answer. The value is comparison plus reuse plus traceability."

## Questions To Ask During The Demo
Ask these during or right after the core workflow:
- Do you already do this in separate tabs today?
- Would reusable personas save you time on client work?
- Is side-by-side comparison useful or unnecessary for your workflow?
- At what point in this flow would you normally drop off?
- Would you trust this for a real client deliverable this week?

## What To Record After The Demo
Immediately log:
- ICP fit confirmed or denied
- where they first understood the value
- where they hesitated or got confused
- what they asked for that is actually important
- whether they would use it on live client work
- the single strongest objection
